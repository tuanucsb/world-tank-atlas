- **What:** Run `/plan-design-review` on the tank gallery and tank pages, the

- **Why:** The 2026-11-05 review (`UX_PLAN.md`) redesigned the header, map and

### First-load loading screen
- **What:** A tiny inline "Loading atlas…" screen with the wordmark, removed
  once the app has initialized.
- **Why:** The page is one 750 KB file plus Tailwind from a CDN. On slow
  connections visitors see unstyled text, then a reflow, with no loading
  feedback.
- **Pros:** About 20 lines of inline HTML/CSS; first impression stays clean on
  any network.
- **Cons:** Mostly unnecessary if the token migration (T1) replaces the
  Tailwind CDN with built CSS.
- **Context:** Decide after T1; if the CDN is gone, check whether a flash
  remains.
- **Depends on:** UX_PLAN T1.
